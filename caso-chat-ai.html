Produto com IA

Chat AI — UI Kit
& Interface Web

Design System Tokens Multi-modo

Contexto

Projeto de um chat baseado em AI para ambiente web, com foco em clareza, consistência e escalabilidade.

O desafio foi criar uma interface simples para o utilizador, mas robusta a nível de sistema, preparada para evoluir.

O meu papel

  • Definição do UI Kit
  • Criação de tokens semânticos
  • Estruturação para múltiplos contextos (default, confidencial, dark)
  • Design da interface e estados do chat
  • Entrevistas contextuais com 5 utilizadores de perfis e responsabilidades distintas — que informaram a definição de assistentes partilhados entre equipas e a priorização de integrações (Jira, Confluence, Outlook).
  • Criação de um canal de testers (RITE Testers no Teams) para recrutamento de utilizadores reais para testes e entrevistas contínuas.
  • Testes de usabilidade informais que identificaram problemas na gestão de documentos, classificação de privacidade e áreas globais de chat.

Abordagem

O foco foi criar um sistema semântico, separando intenção de apresentação, permitindo:

  • Escalabilidade
  • Consistência entre componentes
  • Melhor alinhamento com desenvolvimento

O feedback in-app era praticamente inexistente: os utilizadores tinham de sair da aplicação, aceder ao Jira e registar o issue manualmente. Foi desenhada uma área de feedback contextual integrada para reduzir esse atrito. A adesão não aumentou significativamente, mas a funcionalidade ficou como canal directo de reporte sem abandono da aplicação.

UI Kit & Tokens

  • Tokens organizados por função: texto, superfícies, ações, notificações
  • Estados claros para ações primárias
  • Reutilização entre modos e contextos

Interface do Chat

  1. 01

    Redução da carga cognitiva

  2. 02

    Feedback claro do sistema

  3. 03

    Estados explícitos de interação

  4. 04

    Avaliação da experiência integrada de forma não intrusiva

Resultado

  • Interface consistente e clara
  • Sistema preparado para crescimento
  • UI Kit reutilizável
  • Menos decisões ad-hoc em novos ecrãs
  • Integrações prioritárias (Jira, Confluence, Outlook) definidas com base em entrevistas, não em assunções.
  • Feedback contextual integrado na aplicação, eliminando a necessidade de sair para reportar problemas ou sugestões.

O que este
projeto demonstra

  • Arquitectura de design systems semânticos com tokens multi-modo
  • Capacidade de simplificar para o utilizador sem perder robustez de sistema
  • Processo completo: research, interface e sistema de componentes
